# Карта переноса интерфейса Android → WP8.1

Эталон Android: `app/src/main/java/com/yasn198020/aicontrol/MainActivity.kt` и `IoTManagerWidgetRenderer.kt`.
Целевая ветка: `ui/lumia830-dashboard-test`. Ветка `main` не изменяется.

## Перенос экранов

| Android | WP8.1 | Состояние |
|---|---|---|
| Верхняя панель приложения, заголовок и индикатор MQTT | Постоянная верхняя панель XAML | Добавлена |
| Нижняя навигация: Главная / Марфа / Команды / Сценарии / Отложенные | Нижняя панель Metro: Домой / Марфа / Графики / Задачи / Настройки | Добавлена; пункты адаптированы к существующим WP81-функциям |
| Главный Dashboard и страницы IoTManager | Pivot «Управление», `WidgetPages`, текущий рендерер виджетов | Функциональность сохранена; компоновка приведена к общей оболочке |
| Раздел истории и графиков | Pivot «Графики» | Сохранён |
| Запланированные/отложенные операции | Pivot «Задачи» | Сохранён |
| MQTT, сценарий IoTManager, параметры хранения и голоса | Pivot «Настройки» | Сохранён |
| Обученные команды, hub сценариев, аудит разрешений и очистка Android | Не имеют полностью эквивалентных отдельных экранов в текущем WP81 UI | Отдельный этап; не маскировать несуществующую функциональность |

## Правила соответствия

- Тёмная палитра и голубой акцент Android сохраняются; навигация и верхний заголовок постоянно видимы.
- Не переписываются MQTT-клиент, сценарный исполнитель, расписание, парсер, история и динамическое построение виджетов.
- Все правки этого этапа делаются только в тестовой ветке.
- Визуальный паритет окончательно оценивается по сборке и скриншотам Lumia 830: размеры шрифтов, высоты элементов и доступная область WP8.1 могут потребовать точечной корректировки.
